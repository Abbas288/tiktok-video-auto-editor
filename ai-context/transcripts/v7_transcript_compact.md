# Kompakt transkript vecka 7

## MÅSTE FÖLJAS

* CI/CD ska förstås som del av kvalitet och leverans.
* Projektet ska fortsätta implementeras med testkod.
* QA ska börja: testa appen mot krav och user stories.
* Dokumentation ska fortsätta uppdateras.
* Grupparbete ska visa pipeline och uppdaterad app.

## BRA FÖR RAPPORT

Vecka 7 visar övergången från lokal utveckling till mer professionellt arbetssätt. Manuell deploy är riskabel eftersom steg kan glömmas. Automatisering gör processen mer reproducerbar.

CI betyder att kod verifieras innan den integreras. CD kan betyda delivery eller deployment beroende på hur långt flödet automatiseras.

## BRA FÖR MUNTLIG REDOVISNING

För Abbas projekt kan detta sägas kort:

"Jag använder verifiering och pipeline-tänk för att minska risken att trasig eller AI-genererad kod hamnar i main utan kontroll."

## BAKGRUND

CI/CD-källorna tar upp Docker, Caddy, Nginx, GitLab Runner, Container Registry och Cumulus. Dessa är relevanta för deployment-issues, men ska inte påverka vanlig editorlogik.
