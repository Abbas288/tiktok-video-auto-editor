# Vecka 1 till 2: Vision och planering

## Tema
Vision, projektidé, problemformulering, målgrupp, GitLab Wiki och kursstart.

## Kursens fokus
- Titta på kursintroduktion, vision-inspelning och slides.
- Läsa kapitel 1, 2 och 3.
- Läsa tidigare post mortems.
- Bekanta sig med GitLab Wiki.
- Skriva projektvision.
- Delta i grupparbete och presentation.
- Besvara examinationsfrågor i grupp.

## Abbas projektfokus
Abbas projekt är The TikTok Catalyst / LeTrend Mobile. Projektet ska hjälpa serviceverksamheter, särskilt restauranger och caféer, att skapa trendanpassade TikTok-videor genom ett mallbaserat redigeringsflöde.

Kärnflöde:
`TikTok URL -> AI/API video analysis -> Template-JSON -> EditSession -> Editor UI -> Preview/Timeline -> Compile-payload -> backend/compile-server -> Rendered video via FFmpeg`

## Vad Gemini ska prioritera
- Hjälpa till att formulera problem och värde före teknik.
- Hålla visionen tydlig och avgränsad.
- Förhindra scope creep.
- Se till att Ida och Wasim bara används som referensprojekt.
- Koppla projektvisionen till senare krav och testfall.

## Viktiga wiki-delar
- Projektvision
- Problem och målgrupp
- Liknande lösningar
- Baskrav och unika egenskaper
- Teknikval på hög nivå
- Reflektion från grupparbete

## Risker
- Visionen blir för teknisk.
- Projektet låter som att mobilappen bygger hela AI-pipelinen.
- MVP blir för stort.
- Dokumentationen skrivs men används inte.

## Praktisk koppling till kod
I denna fas ska Gemini inte pressa fram stora implementationer. Kodarbete ska endast stödja projektstart, till exempel repo, Expo-grund, README och tidig struktur.
