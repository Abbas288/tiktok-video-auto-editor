# AI-context theory package

Denna ZIP innehåller AI-vänliga teorifiler för Abbas 1DV613-projekt.

Packa upp i projektroten så att filerna hamnar under:

```text
ai-context/theory/
ai-context/09_theory_index.md
```

Filerna är skrivna för Gemini CLI som arbetsminne, inte som vanliga skolanteckningar.

Varje teorifil innehåller:

1. Kärna i kapitlet
2. Viktiga begrepp
3. Relevans för 1DV613
4. Relevans för Abbas projekt
5. När Gemini ska använda kapitlet
6. Vad som måste synas i wiki, rapport, testning eller presentation
7. Praktisk koppling till projektet

Kärnflödet som återkommer i filerna är:

TikTok URL → AI/API video analysis → Template-JSON → EditSession → Editor UI → Preview/Timeline → Compile-payload → backend/compile-server → Rendered video via FFmpeg
