# #105 — TC-D4: Trasig exportadress hanteras med begriplig felsida

**Förutsättning:** Compile-servern körs och webbläsaren kan nå servern.

**Steg:**

1. Öppna följande trasiga exportadress direkt i webbläsaren:
   http://localhost:3030/compiled/missing-video.mp4
2. Kontrollera sidan som visas.
3. Klicka på knappen för att gå tillbaka.

**Förväntat resultat:** Användaren möts inte av rå teknisk feldata. Sidan visar ett begripligt meddelande om att videon inte längre är tillgänglig och innehåller en tydlig knapp för att gå tillbaka.
