# #128 — TC-CP4: Importerad template styr editorflödet

**Förutsättning:** En giltig JSON-template har importerats och visas som projekt.

**Steg:**

1. Öppna det importerade projektet.
2. Kontrollera att projektets titel och scener kommer från den importerade templaten.
3. Kontrollera att scenmetadata, textöverlägg, filter, ljud och övergångar följer templaten.
4. Lägg till videor för scenerna.
5. Förhandsgranska eller kompilera projektet.

**Förväntat resultat:** Editorn använder den importerade templaten som grund. Befintligt flöde för scenval, video, preview, filter, text, transitions och compile fungerar fortfarande.
