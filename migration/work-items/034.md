# #34 — Fix: Show error message when templates fail to load

The home screen should show a clear error message if templates cannot be loaded.

Currently, the error is only logged in the console, so the user does not get any feedback in the UI.


- An error message is shown if templates fail to load.
- The loading spinner stops after the request fails.
- The user can understand that the templates could not be loaded.
- The change is implemented in a separate branch and submitted through a merge request.
