# #171 — TC-CF3: Appen hanterar kontrollerat compile-fel utan krasch

**Förutsättning:** Appen körs mot en compile-server i test- eller utvecklingsmiljö där compile medvetet kan provoceras att misslyckas.

**Testdata:** Samma trasiga compile-payload som i TC-CF2 används där scenens `videoSource.url` är:

```txt
https://example.invalid/letrend/missing-scene-video.mp4
```

**Steg:**

1. Öppna testprojektet i appen.
2. Starta compile.
3. Vänta på appens felåterkoppling.
4. Fortsätt använda editorn efter felmeddelandet.

**Förväntat resultat:** Appen visar ett begripligt felmeddelande, editorn kraschar inte och användaren kan fortsätta redigera eller försöka igen.

**Status:** Pass/Fail

**Kommentar:** `example.invalid` är medvetet valt som ogiltig testdomän. Testet blir därför reproducerbart och ska inte bero på externa filer eller slumpmässig nätstatus.
