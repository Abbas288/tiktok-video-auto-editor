# #153 — USER STORY: Som användare vill jag läsa mer om template-innehåll så att jag förstår hur appen fungerar

## Syfte

Användaren ska kunna öppna en informationssida från startsidan och snabbt förstå vad en JSON-template innehåller, vad appen gör med den och vad användaren förväntas bidra med.

## Acceptanskriterier

- [x] Startsidan har en åtgärd för att läsa mer om templates.
- [x] Åtgärden öppnar en separat informationssida.
- [x] Informationssidan förklarar kort vad en template innehåller.
- [x] Informationssidan förklarar kort vad användaren behöver göra.
- [x] AI-prompten visas i en tydlig code-snippet-liknande ruta.
- [x] Användaren kan kopiera AI-prompten från informationssidan.
- [x] Användaren kan gå tillbaka till projektöversikten.
- [x] Befintligt import-, projekt- och editorflöde påverkas inte negativt.
- [x] Projektets verifiering passerar.
