# #37 — TC-D2: Lokal körning via Docker Compose

**Förutsättning:** Docker-imagen kan byggas enligt TC-D1 och Docker Desktop är igång.

**Steg:**

1. Kör `$env:WEB_PORT="8080"`.
2. Kör `docker compose up --build -d`.
3. Öppna `http://localhost:8080` i webbläsaren.
4. Kör `curl.exe -I http://localhost:8080`.
5. Kör `docker compose ps` 
6. Kontrollera att containern körs.

**Återställning efter test:** Kör `docker compose down` om containern inte ska fortsätta vara igång.

**Förväntat resultat:** Docker Compose startar containern utan fel. Appens Expo Web-version visas i webbläsaren på `http://localhost:8080`. `curl.exe -I http://localhost:8080` returnerar `HTTP/1.1 200 OK` eller motsvarande lyckad HTTP-status. `docker compose ps` visar att web-containern körs.

**Status:** Fail/Pass
