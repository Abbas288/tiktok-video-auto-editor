# #91 — TC-C2: UI visar tydligt att kompilering pågår

**Förutsättning:** Appen körs och ett projekt är öppet i editorn.

**Steg:**

1. Starta kompilering.
2. Kontrollera att UI visar att kompilering pågår.
3. Försök starta kompilering igen medan första kompileringen fortfarande pågår.
