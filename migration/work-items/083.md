# #83 — TC-R6: Editorpaneler visas och fungerar efter standardisering

**Förutsättning:** Refaktoreringen är implementerad och ett projekt är öppnat i editorn.

**Steg:**

1. Kontrollera att panelen för textöverlägg visas när ett textöverlägg väljs.
2. Kontrollera att panelen för scene effects visas när inget textöverlägg är valt.
3. Kontrollera att ljudpanelen visas när inget textöverlägg är valt.
4. Ändra ett textöverlägg via textpanelen.
5. Ändra ett visuellt filter via scene effects-panelen.
6. Ändra volym via ljudpanelen.

**Förväntat resultat:**
