# #170 — TC-CF2: Compile-server loggar felkällan vid avsiktligt trasig mediareferens

**Förutsättning:** Compile-servern körs i test- eller utvecklingsmiljö och kan ta emot compile requests.

**Testdata:** Compile-payload där första scenens videokälla pekar på en icke-existerande fil.

Testdatafil eller request body:

```json
{
  "templateId": "test-broken-media-reference",
  "sourceVideoUrl": "",
  "orientation": "landscape",
  "originalVolume": 0,
  "music": null,
  "scenes": [
    {
      "id": "scene-1",
      "orderIndex": 0,
      "startSeconds": 0,
      "durationSeconds": 4,
      "instruction": "Broken media reference test",
      "transition": {
        "type": "none",
        "durationSeconds": 0,
        "direction": "none"
      },
      "textOverlays": [],
      "effects": [],
      "videoSource": {
        "url": "https://example.invalid/letrend/missing-scene-video.mp4",
        "sourceStartSeconds": 0,
        "durationSeconds": 4
      }
    }
  ]
}
```

**Steg:**

1. Skicka testdatan ovan till compile-serverns compile-endpoint.
2. Starta compile-processen.
3. Kontrollera serverns loggar.
4. Kontrollera serverns svar.

**Förväntat resultat:** Compile-servern kraschar inte tyst. Servern returnerar ett kontrollerat fel och loggarna visar tydligt att renderingen misslyckades på grund av en otillgänglig mediareferens.

**Status:** Pass/Fail
