# #104 — TC-RF4: Renderingsfel hanteras utan serverkrasch

**Förutsättning:** Compile-servern körs i renderingsläge och kan ta emot export eller compile requests.

**Steg:**

1. Starta export eller kompilering med data som leder till renderingsfel, exempelvis ogiltig källvideo eller ofullständig media-data.
2. Kontrollera appens eller serverns feedback.
3. Kontrollera att servern fortfarande är igång efter felet.
4. Skicka en ny giltig export eller compile request efter felet.

**Förväntat resultat:** Systemet visar tydlig feedback när renderingen misslyckas. Servern kraschar inte och kan hantera nya giltiga requests efter felet. Appen låser sig inte och användaren kan fortsätta arbeta i editorn.

**Status:** Pass/Fail
