# #25 — TC1.6 Ogiltigt template-id kraschar inte appen

**Förutsättning:** Appen körs och editor route kan öppnas med valfritt template-id.

**Steg:**

1. Starta appen.
2. Öppna `/editor/missing-template-id`.
3. Kontrollera att appen inte kraschar.
4. Kontrollera att editor-vyn visar ett tydligt error state.
5. Kontrollera att ingen gammal template eller tidigare editor-session visas.

**Förväntat resultat:** Appen kraschar inte och visar ingen White Screen of Death. `/editor/missing-template-id` leder till ett tydligt error state för ogiltigt template-id. Ingen tidigare laddad template eller gammal editor-session ligger kvar i vyn.

**Status:** Pass/Fail
