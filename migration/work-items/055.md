# #55 — TC-O6: Återgivning av specialtecken och emojis

**Förutsättning:** En mall innehåller en textöverlagring med emojis och icke-latinska tecken (t.ex. "🐰 🦋 漢字").

**Steg:**

1. Kör det automatiska testet för Unicode-tecken via `npm test`.
2. Lägg in samma tecken i appens mockdata.
3. Spela upp videon i editorn fram till textens tidpunkt.

**Förväntat resultat:** Jest validerar att tecknen kan parsas. React Native renderar alla tecken och emojis visuellt korrekt. Inga "trasiga" symboler (frågetecken/fyrkanter) visas på skärmen.

**Status:** Fail/Pass
