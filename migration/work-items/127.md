# #127 — TC-CP3: Användaren kan kopiera AI-prompt för template-generering

**Förutsättning:** Appen körs och användaren befinner sig där projekt kan skapas.

**Steg:**

1. Tryck på knappen för att kopiera AI-prompt.
2. Kontrollera att användaren får feedback om att prompten kopierats.
3. Klistra in prompten i ett externt textfält.
4. Kontrollera att prompten beskriver vilken JSON-template editorn behöver.

**Förväntat resultat:** Prompten kopieras och kan användas som stöd för att generera en template enligt editorns krav.
