# #74 — TC-A4: Användaren kan använda mute-knappen för varje ljudkälla

**Förutsättning:** Appen körs och ett projekt med både originalljud och bakgrundsmusik är öppnat i editorn.

**Steg:**

1. Lokalisera ljudkontrollpanelen i editorn.
2. Tryck på mute-knappen bredvid volymkontrollerna för "Original Audio".
3. Starta uppspelningen.
4. Kontrollera att originalljudet är tyst medan bakgrundsmusiken fortfarande kan höras.
5. Tryck på samma knapp igen för att slå på originalljudet.
6. Tryck på mute-knappen för "Background Music".
7. Kontrollera att bakgrundsmusiken är tyst medan originalljudet fortfarande kan höras.

**Förväntat resultat:** Mute-knappen sätter vald ljudkälla till 0 procent. När mute-knappen trycks igen återställs ljudkällan till hörbar volym. Varje mute-knapp påverkar bara sin egen ljudkälla. Appen kraschar inte.

**Status:** Pass/Fail
