# #43 — TC-E1: Editor och preview hanterar saknat eller ogiltigt template-id

**Förutsättning:** Appen körs med `npm start`. Template `bunny-intro-2026` finns.

**Steg:**

1. Öppna `/`.
2. Kontrollera att Home-vyn renderas.
3. Öppna `/editor/bunny-intro-2026`.
4. Kontrollera att editorn laddas för rätt template.
5. Öppna `/editor/missing-template-id`.
6. Kontrollera att editorn visar ett tydligt error state.
7. Kontrollera att tidigare editor-session inte ligger kvar efter ogiltigt template-id.
8. Öppna `/preview/bunny-intro-2026`.
9. Kontrollera att preview-vyn hanterar template-id utan krasch.
10. Om tom template-lista kan simuleras, kontrollera att Home visar ett tomt läge.

**Förväntat resultat:** Home-vyn renderas utan krasch. Template `bunny-intro-2026` laddar editor-vyn korrekt. Ogiltigt template-id visar ett tydligt error state och rensar tidigare session. Preview-vyn öppnas med giltigt template-id utan krasch. Om tom template-lista simuleras visar Home ett tomt läge i stället för blank sida eller krasch.

**Status:** Pass/Fail
