# #33 — FIX: "Go back"-knappen fungerar inte vid direktnavigering till ogiltigt ID

## Mål

Åtgärda en navigationsbugg som upptäcktes under testning av TC1.6. När en användare navigerar direkt till ett ogiltigt template-ID via URL:en visas rätt felmeddelande, men "Go back"-knappen reagerar inte.

## Problem

Knappen använder `router.back()`. Vid direkt inmatning av en URL i webbläsaren (t.ex. `http://localhost:8081/editor/ogiltigt-id`) finns det ingen navigationshistorik i stacken. Eftersom historiken är tom händer ingenting när funktionen anropas.

## Åtgärd

- [x] Uppdatera `handleGoBack` i `app/editor/[id].tsx` så att den använder `router.replace("/")` eller navigerar till roten istället för att lita på historiken när appen befinner sig i ett error-state.

## Acceptanskriterier

- [x] Om användaren skriver in `http://localhost:8081/editor/invalid-123` och klickar på "Go back", ska användaren skickas tillbaka till startsidan (`/`).
