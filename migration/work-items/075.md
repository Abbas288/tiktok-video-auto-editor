# #75 — TC-R1: Volymvärden hanteras konsekvent efter refaktorering

**Förutsättning:** Refaktoreringen är implementerad och projektets automatiska tester kan köras.

**Steg:**

1. Kör tester som verifierar att volymvärden under 0 behandlas som 0.
2. Kör tester som verifierar att volymvärden över 1 behandlas som 1.
3. Kör tester som verifierar att ett normalt volymvärde, exempelvis 0.5, bevaras som 0.5.
4. Kör tester som verifierar att höjning och sänkning av volym sker stegvis utan att värdet går utanför intervallet 0 till 1.
5. Kör tester som verifierar att mute sätter volymen till 0 och att unmute återställer ljudet till en hörbar nivå.

**Förväntat resultat:**\
Volymhantering är konsekvent för gränsvärden, normala värden, stegvisa ändringar och muting. Inga volymvärden utanför intervallet 0 till 1 används vidare i applikationen.

**Status:** Pass/Fail
