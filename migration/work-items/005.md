# #5 — USER STORY: Som användare vill jag att text från mallen visas ovanpå videon vid exakt rätt tidpunkt, så att rätt budskap framgår.

För att kunna rendera textöverlagring (text overlay) på videon utan att den hamnar utanför bilden behöver vi bygga en "video stage". Denna stage måste synkronisera videons tid med de text-overlays som definierats i mallen. Logiken för positionering och tidshantering ska vara helt frånkopplad från UI:t och täckas av automatiserade tester.

## Acceptanskriterier

- [x] Textöverlagringar visas och döljs synkroniserat med videons aktuella uppspelningstid.
- [x] Texten renderas med rätt storlek, färg, stil och position enligt mallens JSON-data.
- [x] Ett isolerat "Video Stage" introduceras så att textlagret ligger fixerat ovanpå videon men under uppspelningskontrollerna.
- [x] Helskärmsläge stöds på ett sätt som bibehåller textens skalning och placering ovanpå videon.
- [x] Edge cases (tomma strängar, extremt långa texter, överlappande texter och unicode/emojis) hanteras säkert utan att krascha appen eller spräcka layouten.
- [x] Domänlogiken för textrendering är frikopplad från UI-events och testas via automatiserade enhetstester.
