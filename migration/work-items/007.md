# #7 — USER STORY: Som användare vill jag kunna lägga till visuella filter (ljusstyrka, kontrast, zoom) på en specifik scen.

Användaren ska kunna anpassa enskilda scener oberoende av varandra med kontroller för ljusstyrka, kontrast och zoom. Ändringarna ska uppdateras i realtid, appliceras endast under den aktiva scenens tidsintervall och sparas både i den pågående redigeringssessionen och som utkast. Implementationen ska behålla tydlig separation mellan presentation, domänlogik och state samt hantera extrema filtervärden på ett säkert sätt. 

Avancerad färggradering, keyframes, animerade filterövergångar och backend-export av filter ingå inte i det här utvecklingssteget.

## Acceptanskriterier

- [x] Användaren kan ändra ljusstyrka för vald scen.
- [x] Användaren kan ändra kontrast för vald scen.
- [x] Användaren kan ändra zoom för vald scen.
- [x] Användaren kan flytta zoomfokus inom videoklippet när inzoomning är aktiverad.
- [x] Filter appliceras endast på den scen där de är inställda.
- [x] Filter uppdateras visuellt i previewen när videon spelas inom scenens tidsintervall.
- [x] Andra scener påverkas inte av ändringen.
- [x] Filtervärden sparas i den aktiva redigeringssessionen.
- [x] Filterändringar finns kvar när projektet öppnas igen.
- [x] Reset återställer scenens filtervärden till standardläge.
- [x] Kodens struktur behåller separation mellan presentation, domänlogik och state.
