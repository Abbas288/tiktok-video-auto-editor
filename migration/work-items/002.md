# #2 — USER STORY: Som användare vill jag att källvideon spelas upp i editorn, så att jag visuellt kan granska det rörliga materialet jag redigerar istället för att se en tom yta.

Vi behöver implementera en videospelare som dynamiskt läser in och spelar upp den källvideo som är definierad i den aktuella mallen. Lösningen ska vara stabil och kunna hantera felaktiga länkar utan att krascha hela applikationen.

## Acceptanskriterier

- [x] Editor-vyn renderar en videospelare som ersätter det tidigare tomma läget/platshållaren.
- [x] Videospelaren laddar den videolänk som finns angiven i det aktuella editor-statet.
- [x] Användaren kan starta och pausa videon.
- [x] Om videolänken är ogiltig, trasig eller saknas, hanteras detta säkert (t.ex. med en svart skärm eller ett felmeddelande) och appen kraschar inte.
- [x] Implementationen följer projektets arkitektur (separerar UI från domänlogik).

- #45

Testtäckningen omfattar videouppspelning i editorn, laddning av videolänk från aktuellt editor-state, start/paus och säker hantering av ogiltig eller saknad video-URL.

- [x] Samtliga kopplade testfall är godkända.
