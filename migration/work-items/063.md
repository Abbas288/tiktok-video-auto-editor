# #63 — TC-C1: Merge Request verifieras automatiskt med verify-steget


**Förutsättning:** En branch med ett medvetet linting-fel eller ett trasigt test pushas upp och en Merge Request skapas.

**Steg:**
1. Skapa en Merge Request för branchen.
2. Gå till GitLab-pipelinens vy för Merge Requesten.
3. Kontrollera att `verify_app` körs automatiskt.
4. Kontrollera resultatet för linting, TypeScript-kontroll och tester.

**Förväntat resultat:** `verify_app` misslyckas och visas som rött om linting, TypeScript-kontroll eller tester fallerar. Om projektet kräver grön pipeline för merge ska GitLab förhindra merge tills felet är åtgärdat.

**Status:** Pass/Fail
