# #31 — TC2.6 EditSession sparar aktiv scen

**Förutsättning:** `useEditSession` är tillgänglig och store kan hålla aktuell template och aktiv scen.

**Steg:**

1. Återställ store till startläge om tidigare state finns.
2. Ladda `mockBunnyTemplate` i store.
3. Kontrollera att `currentTemplate.id` är `bunny-intro-2026`.
4. Välj första scenen som aktiv scen.
5. Kontrollera att `activeSceneId` blir `scene-1`.

**Förväntat resultat:** Store innehåller vald template efter laddning. `currentTemplate.id` är `bunny-intro-2026`. Första scenen kan väljas som aktiv scen och `activeSceneId` uppdateras till `scene-1`.
