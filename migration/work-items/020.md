# #20 — TC1.1 Home-vyn renderar template-listan

**Förutsättning:** Appen kan startas med Expo Router och mockTemplate finns tillgänglig.

**Steg:**

1. Kör `npx expo start`.
2. Öppna appens home route.
3. Kontrollera att rubriken `Available Templates` visas.
4. Kontrollera att template `The Bunny and the Butterfly` visas.
5. Kontrollera att antal scener visas som `2 scenes`.

**Förväntat resultat:** Home route renderas utan krasch. Rubriken `Available Templates` visas. Template `The Bunny and the Butterfly` visas på startsidan och antal scener visas som `2 scenes`. Testet verifierar att appens första vy kan visa mockad template-data.

**Status:** Pass/Fail
