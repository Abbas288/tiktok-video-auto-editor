# #96 — SYSTEM: Systemet ska hantera en minimal compile-server integration för render-pipeline

SYSTEM: Compile-server för första fungerande exportflöde

Compile-servern ska göra det möjligt för appen att skicka en aktiv redigeringssession och få tillbaka en färdig video som appen kan hantera. Första versionen behöver inte göra fullständig FFmpeg-rendering, utan får returnera en testvideo eller placeholder-output för att verifiera klient-server-flödet. Syftet är att skapa en fungerande grund för exportflödet som sedan kan byggas ut stegvis.

## Acceptanskriterier

- [x] Appen kan skicka den aktiva redigeringssessionen till compile-servern.
- [x] Servern tar emot och kontrollerar att nödvändig data finns.
- [x] Servern returnerar ett svar som appen kan använda som färdig kompilerad video.
- [x] Första versionen kan använda testvideo eller placeholder-output.
- [x] Appen kan konfigureras att använda compile-servern.
- [x] Appen visar tydlig status under exportflödet.
- [x] Fel från servern hanteras tydligt utan att appen kraschar.
- [x] Lösningen är byggd så att riktig rendering kan läggas till senare.
- [x] Projektets verifiering passerar.
