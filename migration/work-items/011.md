# #11 — USER STORY: Som användare vill jag kunna välja en övergång mellan två scener på tidslinjen, så att projektets klippflöde blir tydligare och kan förberedas för en snyggare export.

När användaren arbetar i editorn ska det finnas ett klickbart område mellan scenerna på tidslinjen. Där ska användaren kunna välja vilken övergång som ska användas från en scen till nästa. Valet ska visas i tidslinjen, kunna ändras i efterhand och sparas i projektets utkast så att övergångarna finns kvar när projektet öppnas igen.

## Acceptanskriterier

- [x] Ett klickbart område visas mellan scenerna på tidslinjen.
- [x] Användaren kan välja mellan minst tre övergångstyper.
- [x] Tillgängliga övergångstyper inkluderar Cut, Fade och Slide.
- [x] Vald övergång visas tydligt i tidslinjen.
- [x] Användaren kan ändra en tidigare vald övergång.
- [x] Övergången kopplas till rätt plats mellan två scener.
- [x] Vald övergång sparas i projektets utkast.
- [x] Sparad övergång finns kvar när samma projekt öppnas igen.
- [x] Befintliga editorfunktioner som scenval, textöverlägg, scene effects och ljudkontroller fungerar som tidigare.
- [x] Projektets verifiering passerar.
