# #113 — REFACTOR: Minska ansvar i editor-controller och förbättra testbarheten

## Syfte

Editorns controller har vuxit och ansvarar nu för flera separata flöden samtidigt. Det gör koden svårare att läsa, testa och vidareutveckla.

Målet är att förbättra ansvarsfördelningen i editorflödet utan att ändra användarens upplevelse. Presentation, application-logik, domänlogik och infrastructure ska hållas separerade.

Refaktoreringen ska inte införa ny funktionalitet. Den ska bevara nuvarande beteende för scenval, preview, textöverlägg, scene effects, transitions, ljud, egna scenvideor och kompilering/export.

## Acceptanskriterier

- [x] Editorflödet fungerar som tidigare efter refaktoreringen.
- [x] Editor-controllern har ett tydligare och mindre ansvar.
- [x] Separata editorflöden är lättare att testa var för sig.
- [x] Presentation-komponenter innehåller inte ny affärslogik.
- [x] Domänlogik ligger fortsatt i domain-lagret.
- [x] Infrastructure-anrop ligger utanför UI-komponenter.
- [x] Befintliga kontrakt mot store, template-data och compile-flow bevaras.
- [x] Befintliga tester påverkas inte negativt.
- [x] Relevanta tester läggs till där ansvar har flyttats eller avgränsats.
- [x] Projektets verifiering passerar.
