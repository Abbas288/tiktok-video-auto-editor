# #140 — TC-PM4: Användaren kan ta bort eller avbryta radering av projekt

**Förutsättning:** Minst ett projekt finns på startsidan.

**Steg:**

1. Öppna projektets åtgärder.
2. Välj att ta bort projektet.
3. Avbryt raderingen.
4. Kontrollera att projektet finns kvar.
5. Välj att ta bort projektet igen.
6. Bekräfta raderingen.

**Förväntat resultat:** Avbruten radering påverkar inte projektet. Bekräftad radering tar bort projektet från projektlistan.

**Status:** Pass/Fail
