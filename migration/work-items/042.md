# #42 — FIX: Stabilisera template-id i editor och preview

Just nu finns det risk att editorn fastnar i loading om id saknas. Det finns även risk för stale state om användaren först laddar en giltig template och sedan öppnar en ogiltig editor-route.

Det är en stabilitetsfix för befintlig Expo Router.


- [x] Saknat eller ogiltigt template-id visar error state.
- [x] Gammal editorstate rensas när template inte hittas.
- [x] Editor och preview hanterar route-parametrar konsekvent.
- [x] Home visar tomt läge om templates saknas.
- [x] `npx tsc --noEmit` passerar.

## Testfall

Följande testfall har skapats för detta issue:

- [x] TC-E1: Editor och preview hanterar saknat eller ogiltigt template-id
