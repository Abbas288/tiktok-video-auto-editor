# #72 — TC-A2: Användaren kan justera och tysta ljudkällor via editorn

**Förutsättning:** Appen körs och ett projekt med både originalljud och bakgrundsmusik är öppnat i editorn.

**Steg:**

1. Lokalisera ljudkontrollpanelen i editorn.
2. Sänk originalljudet till 0 procent.
3. Starta uppspelningen och kontrollera att originalljudet är tyst.
4. Höj originalljudet igen.
5. Sänk bakgrundsmusiken till 0 procent.
6. Kontrollera att bakgrundsmusiken är tyst medan originalljudet fortfarande kan höras.
7. Justera båda ljudkällorna till valfri nivå mellan 0 och 100 procent.

**Förväntat resultat:** Volymändringar märks direkt under uppspelning. Vid 0 procent är vald ljudkälla tyst. Appen kraschar inte och övriga ljudkällor påverkas inte felaktigt.

**Status:** Pass/Fail
