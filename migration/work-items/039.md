# #39 — TC-D4: Säkerhetskontroll före commit

**Förutsättning:** Deploymentfiler har skapats eller ändrats och ändringarna är ännu inte committade.

**Steg:**

1. Kör `git status`.
2. Kontrollera vilka filer som är ändrade, nya eller staged.
3. Kontrollera att inga privata nycklar, `.env`-filer, certifikat, tokens eller andra secrets finns med.
4. Kontrollera att endast relevanta deploymentfiler, till exempel Docker-, Compose-, Nginx- eller Caddy-konfiguration, ingår i ändringen.
5. Kör vid behov `git diff` eller `git diff --staged` för att granska innehållet innan commit.

**Förväntat resultat:** Git visar endast relevanta deployment- och konfigurationsfiler. Inga privata nycklar, `.env`-filer, certifikat, tokens eller andra secrets är inkluderade. Diffen innehåller inga orelaterade kodändringar eller skräpfiler.

**Status:** Fail/Pass
