# #40 — TC-D5: HTTPS och certifikat fungerar på Cumulus

**Förutsättning:** eduVPN är anslutet, SSH fungerar mot Cumulus och Docker Compose-deploymenten har uppdaterats med Caddy.

**Steg:**

1. Kontrollera att LNU Campus Root CA finns på Cumulus-servern.
2. Sätt `DOCKER_HOST=ssh://cumulus-1dv613`.
3. Kör `docker compose up --build -d`.
4. Kör `docker compose ps`.
5. Kör `docker compose logs caddy`.
6. Kör `curl.exe -I http://cu1223.camp.lnu.se`.
7. Kör `curl.exe -k -I https://cu1223.camp.lnu.se`.
8. Öppna `https://cu1223.camp.lnu.se` i webbläsaren.

**Förväntat resultat:** Caddy- och web-containern körs utan fel. HTTP omdirigerar till HTTPS. HTTPS returnerar `HTTP/1.1 200 OK` och appens Expo Web-version visas i webbläsaren.

**Status:** Fail/Pass
