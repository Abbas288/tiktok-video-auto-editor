# #94 — TC-D2: Användaren kan spara eller ladda ner färdig video lokalt

**Förutsättning:** En färdig video finns tillgänglig i appen efter kompilering.

**Steg:**

1. Tryck på åtgärden för att spara eller ladda ner videon.
2. Godkänn behörighet om appen frågar.
3. Vänta tills åtgärden är klar.
4. Kontrollera att appen visar feedback.
5. Kontrollera att videon finns tillgänglig lokalt där plattformen stödjer det.

**Förväntat resultat:** Den färdiga videon kan sparas, öppnas eller laddas ner på ett sätt som plattformen stödjer. Appen visar tydlig lyckad feedback och kraschar inte.

**Status:** Pass/Fail
